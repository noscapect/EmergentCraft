# Roadmap

1. Validate Continuity of Mind in long-lived live worlds: recall, projects, beliefs, social history, and consolidation are now present without a reward system.
2. Add only further validated physical primitives when warranted: equipment, eat, and eventually crafting.
3. Extend range-limited speech/hearing only without a relationship meter.
4. Add safe learned skill/macro compositions of primitives—never generated JavaScript or Java.
5. Improve long-term memory retrieval and run comparative model experiments.
6. Support multiple inhabitants, self-generated projects, cooperation/conflict, settlements, and only much later generations/culture mechanics.

Third-party runtime dependencies are Fabric Loader/API (Apache-2.0) and the selected local Ollama model under its own model license. No Minecraft assets, accounts, credentials, or Ollama model files are bundled.
